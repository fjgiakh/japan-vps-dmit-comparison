## 三条线路到底是什么意思

对新手来说，CN2 GIA、CMI 这些名字容易搞混，快速解释一下：

**CN2 GIA**：中国电信旗下的优质国际专线，全称 Global Internet Access。路径短、丢包低，晚高峰表现比普通线路好很多。电信用户跑 CN2 GIA，速度稳定性是最优解。

**AS9929 / 10099**：联通的精品路由，效果类似 CN2 GIA，但针对联通用户。

**CMI**：中国移动国际出口，移动用户走这条直连，延迟和速度在三条里相对均衡，不是最快但覆盖稳定。

**国际线路（Tier 1）**：就是普通 BGP 路由，经过 NTT 等国际骨干网，不保证大陆直连质量，晚高峰容易绕路或者丢包。
